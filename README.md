## pyTex - tools for MTEX in python

MTEX is a very well known utility for the analysis of crystallographic texture data in Matlab.
Very recently, The team behind MTEX revealed they now have all of the functionality of MTEX available in python.

This allows matflow the opportunity to execute texture-related tasks in python, overcoming the need to purchase a Matlab licence to analyse texture.
This repository is for building small standalone tasks that use MTEX in python to perform texture analysis and manipulation.
As such, see the following roadmap for planned features:
 - Generation of random texture
 - Sampling texture
 - Reading texture from txt, crc or HDF5.
